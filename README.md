# Happy Birthday Khushi 🎂✨

A Vite + React + TypeScript interactive birthday website.

## Run in VS Code

Prerequisite: install Node.js (LTS).

```bash
npm install
npm run dev
```

Then open the URL shown by Vite (normally `http://localhost:3000`).

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

This is a client-side Vite app. No backend or Gemini API key is required for the current code.

Recommended:
1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Leave the framework as Vite/React (auto-detected).
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.

All photos/videos/audio used by the birthday page are inside `public/`.
